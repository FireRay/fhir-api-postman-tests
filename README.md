# FHIR API Test Suite

A Postman collection demonstrating API testing against a public HL7 FHIR R4 server.

## Features

- Patient CRUD operations
- HTTP validations
- Data validations
- Business validations
- Collection Runner support

## Technologies

- Postman
- REST APIs
- HL7 FHIR R4
- JSON
